## Seeded double-tap correction (2026-10-04, 08:50 UTC)

The pre-round tip in OBS-2026-10-04-01 prompted correction of the provisional
single-press drop. Down now requires two validated press edges while grounded
on a one-way deck. A single press or a held key does not drop. Both presses may
arrive in one fixed tick. The existing seed is 12 ticks (inclusive second-press
boundary), not a measured Y8 timing. Jump, climb, leaving the deck and death
clear pending taps; reset creates a fresh simulation. Focus loss releases held
input through the existing buffer, while a pending tap ages with simulation
ticks; focus is not currently a separate gesture-cancel command.

Pending tap state participates in the snapshot and canonical replay hash, so
the simulation schema is now `sa03.simulation.v3`. Original calibration geometry
