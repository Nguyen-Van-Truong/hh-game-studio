reference/flash/ is a full copy of the Newgrounds 575163 FFDec extract
(scripts, sprites, sounds, images, shapes, fonts, texts, buttons, morphshapes)
plus superfighters-575163.swf.

These files are the original game's extracted resources, kept so the Godot
project is complete. The playable loop is game/*.gd, written for Godot 4.7.2.
It ports the fighter constants and the match flow. It does not recompile the
599 ActionScript classes or the embedded Box2D.
