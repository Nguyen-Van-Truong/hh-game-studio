## Current implementation

The product now has a clean-room greybox relay yard and a live match room:

- `MatchSession` keeps the fixed 60 Hz `Simulation` authority and adds match
  phase/result state, pistol/shotgun slots, grenades, pickups and shot/explosion
  presentation events.
- Weapons and grenade pickups require the Classic interaction gesture
  `Down + Punch`; pill/medkit pickups are collected by walking through them.
- `ClassicBot` emits held intent through `BotInput`, which derives the same
  pressed/held/released `InputFrame` contract as a human player.
- Holding the firearm key enters an explicit aiming state; Up/Down (or W/S)
  changes a bounded elevation angle, and releasing the firearm key consumes
  ammunition and queues the shot. The live view renders this provisional aim
  ray; jump, drop-through and ladder transitions are gated while aiming, and
  hit authority now uses the same bounded ray segment as the event cue. This is
  an implementation contract, not a measured reference value.
- `match_room.tscn` is local 2P; `match_room_bot.tscn` is the explicit bot route
  used by bootstrap key `B`. `V` remains local 2P. Hero/special-character
  controls remain unbound and locked for SA-14.
- Invalid map paths, malformed table rows, and invalid scalar geometry fail
  closed as an `invalid` match phase. Snapshots freeze nested rows and keep
  the world pickup view synchronized with the active match inventory.

All geometry, UI, map data and bot policy are original product work. No Y8
asset, package, title card, code or screenshot is shipped.
