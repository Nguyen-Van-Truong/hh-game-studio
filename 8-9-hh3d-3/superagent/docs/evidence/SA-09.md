# SA-09 — provisional navigation graph

This is a technical foundation only. It does not claim six-map coverage,
reference topology, bot parity, owner acceptance or an SA-09 checkbox.

`game/ai/navigation_graph.gd` builds a deterministic graph from the existing
`ArenaState` topology. Platform centers, ladder endpoints and bidirectional
ladder/platform links are ordered and hashed deterministically. Same-level
platform shortcuts are bounded and skip any edge whose platform span crosses
an authored pit. Platform, ladder and pit geometry is validated before graph
construction; snapshots deep-freeze node rows. A snapshot seam makes malformed
and reordered topology testable without adding map data. No new map data was
added and `relay_yard.json` remains the only `MatchSession` default.

## Input and failure-state hardening (2026-10-06)

The graph builder now accepts decoded JSON rows with String keys, rejects
strings, booleans, nulls and non-finite numeric geometry, and clears all
partially built nodes/edges when validation fails. This keeps a failed build
from exposing a misleading partial route graph. The focused run passed 15
