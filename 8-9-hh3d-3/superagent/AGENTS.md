# Superagent Classic

This directory is the clean-room game worktree for the SA4 plan. Read
`../zdoc/18-9-superagent-2d-y8-plan.txt` from the main checkout before changing
scope. Classic parity is required before any variant. Do not copy code, art,
audio, screenshots, or layout files from the reference game or Vault Fighters.

Use the pinned Godot 4.7.2 executable only. Before any Godot, Blender, browser
capture, export, or test command, check `%LOCALAPPDATA%\\HHGodotAgent\\measure-window.lock`.
If it exists, stop and wait. Keep the simulation fixed at 60 Hz and keep
presentation effects outside the deterministic gameplay state and hash.
