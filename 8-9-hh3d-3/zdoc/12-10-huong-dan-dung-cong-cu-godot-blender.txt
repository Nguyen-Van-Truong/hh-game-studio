3. BẮT ĐẦU NHANH: CÀI ADDON VÀO PROJECT GAME
Đã chạy thật 12-10 14:58 trên một project trống trong %TEMP%: cài COMMITTED, gửi lại cùng
command_id trả đúng receipt cũ, addon 5 file, project.godot và file save không đổi, gỡ COMMITTED.
Luồng giống hàng P9 của gói (studio/tests/conformance/gt10pc_p9_consumer.py:45-60).

    from pathlib import Path
    from studio.package.trust import load_trust
    from studio.package.release_contract import verify_package
    from studio.package.consumer_install import ConsumerInstall

    ART = Path("studio/.local/reviews/gt10pc-rehearsal-20261012-c3h/artifacts/windows")
    keys = load_trust(Path("studio/.local/gt10pc-publisher-v2/trust.json"),
        expected_sha256="2d19e3e90a719ead39cd1874193f90f98e9f8b2e2b71fb9d0ea451c7336af2e0")
    verify_package(ART / "release.hhpkg", trusted_keys=keys, target="Windows")
    installer = ConsumerInstall(Path(r"D:\...\mygame-hh-install"), trusted_keys=keys)
    receipt = installer.install_lifecycle(Path(r"D:\...\mygame"), ART / "release.hhpkg",
        command_id="mygame.hh.install.1", expected_state_sha256="ABSENT")
    state = installer.snapshot()        # state["state_sha256"] là token cho lệnh kế tiếp

- Dùng đường dẫn tuyệt đối, không symlink. Install root là thư mục riêng ngoài project; nó giữ
  các release đã cài và journal trạng thái (schema hh-studio-install-4). Không xóa tay.
- Lần cài đầu expected_state_sha256 là "ABSENT"; lần sau dùng state["state_sha256"] mới nhất.
- Gửi lại cùng command_id với cùng yêu cầu thì nhận lại receipt cũ; giữ id mà đổi nội dung là
  conflict. installer.lookup(command_id) đọc receipt đã có.
- Addon được chép vào <project>/addons/hh_studio/ (plugin.cfg, plugin.gd, scene_commands.gd,
  jcs_godot.gd, SCENE_COMMANDS.md). Hàm cài không sửa project.godot. Muốn bật plugin thì thêm:
    [editor_plugins]
    enabled=PackedStringArray("res://addons/hh_studio/plugin.cfg")
  Khi không có host (biến HH_EDITOR_TOKEN rỗng) plugin không làm gì: editor headless mở bình
  thường, stderr rỗng (đã thử 12-10 14:59). Plugin chỉ gắn lệnh vào scene có root là Node3D
  (godot-addon/addons/hh_studio/plugin.gd:42).
- Nâng cấp: installer.install_upgrade(project, ART / "upgrade.hhpkg", command_id=...,
  expected_state_sha256=token). Hàm này chính là install_lifecycle.
- Rollback: installer.rollback_lifecycle(project, command_id=..., destination=state["previous"],
  expected_state_sha256=token). Chỉ về release trusted đã cài trước đó.
- Gỡ addon: installer.uninstall_addon(project, command_id=..., expected_state_sha256=token).
  Xóa file addon, giữ art/game/source/save; còn lại thư mục rỗng addons/hh_studio và release
  vẫn active (tắt bằng installer.deactivate(command_id=..., expected_state_sha256=token)).
  Gỡ dòng [editor_plugins] trước khi gỡ addon để editor không báo thiếu plugin.
- Sửa addon bị lệch: installer.install_addon(project, command_id=..., expected_state_sha256=token,
  repair=True, release=<id release>). File không do installer sở hữu bị từ chối, không ghi đè.
- Dừng khẩn: installer.stop(); sau khi phục hồi xong: installer.resume().
- Báo lỗi kèm gói support đã lọc secret: studio.package.consumer_support.support_bundle(artifact,
  output, trusted_keys=keys, target="Windows", install=installer); output phải chưa tồn tại.
- gt10pc_p9_consumer.py và run_gt10pc_matrix.py là harness kiểm gói, không phải trình cài.

5. GỬI LỆNH: ENVELOPE, READBACK, UNDO, LEASE
- Mọi mutation là một Request (studio/protocol/core.py), schema_version "hh-studio-0.1", gồm
  command_id, project_id, operation, lease_id, fencing_epoch, expected_revision, target, payload,
  payload_hash ("sha256:" + sha256 của canonical JSON payload), deadline_ms.
- ACK chỉ có sau khi đọc lại trạng thái thật từ Godot. Dòng PASS trong log không phải ACK.
- command_id là duy nhất; gửi lại là idempotent. Lệnh mang fencing_epoch cũ bị từ chối.
- Ba đường đã có, không trộn:
  A) EditorOwner (godot-addon/editor_owner.py): mở editor headless có addon, bridge 127.0.0.1
     với token một lần qua env HH_EDITOR_*; prepare_edit rồi apply_edit, đọc lại inspect().
     Thay đổi nằm trong bộ nhớ editor, lưu file là bước riêng; undo/redo một bước (scene.undo,
     scene.redo, xem studio/tests/godot/test_contract.py).
  B) HTTP (host/core/transport.py, godot-addon/publication_transport.py): POST /v1/commands,
     /v1/lease, /v1/lease/enqueue, /v1/lease/poll, /v1/lease/cancel; cổng control /v1/lookup,
     /v1/stop; header Authorization: Bearer. Writer FIFO tối đa 8 người chờ, 64 ticket; ticket
     không còn sau khi host restart (godot-addon/operations.json).
  C) Gameplay-source GT-09 (godot-addon/gameplay_source_owner.py, gameplay_source_adapter.py):
       owner = GameplaySourcePublicationOwner.create(parent, project_id=..., source_files=...,

  studio/AUTHORING_STATUS.md và sửa file này trong cùng commit. Không tự sửa được thì thêm một
  khối vào cuối zdoc/12-10-gt11-yeu-cau-tu-agent-game.txt, kèm lệnh, input và JSON lỗi.
- Đóng editor Godot trước lệnh ghi trên project đó. --allow-open-editor chỉ dùng khi chắc editor
  không mở scene đó, vì editor có thể ghi đè file khi lưu.
- Mỗi lệnh ghi chạy Godot hai lần (áp op, rồi đọc lại): khoảng 2–5 giây. Gom nhiều op vào một
  file thay vì gọi từng op.

Giới hạn gamekit hiện tại:
- Chỉ sửa scene text .tscn. Resource ngoài (.tres) chỉ load và tham chiếu, chưa sửa qua lệnh.
- Undo chỉ về trước một lệnh khi file chưa bị sửa sau lệnh đó; chưa có redo.
- scene apply không tự kiểm hình ảnh hay gameplay; sau khi sửa, chạy hh play, hh bot, hh shot,
  hh vcheck và hh perf.
- Gamekit chưa nằm trong gói .hhpkg đã ký; chạy từ source của repo này.
