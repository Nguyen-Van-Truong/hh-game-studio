# GT-03 Godot adapter — implementation candidate

The managed fixture host joins authenticated HTTP to the actual Windows
EditorPlugin, protected journal/selector storage, and bounded Linux validation.
The tools plan remains the sole gate-progress authority. Successful component
runs retain their own source hashes and do not constitute GT-03 acceptance.

`publication_owner.py` implements inspect/preview, typed node create/update/
remove, native UndoRedo, `scene.save`, and closed-profile `script_text.replace`.
Registered grants, leases, fences and deadlines are rechecked before each
effect. Work and control listeners are separate and use unchanged GT-02 framing.

Editor edits keep native history and selected project files unchanged.
Journal V5 stores a private checkpoint before the effect and the exact response
after registered readback. The receipt states `effect_scope=editor_session`,
`files_saved=false`, `live_state_durable=false`. Explicit save publishes the
complete eleven inputs and manifest at a declared history boundary. Script
replacement retires the previous editor before opening the selected successor.

`recovery_host.py` exposes separate authenticated readonly reconciliation.
Fresh fenced authority, actual new editor readback and a same-custody terminal
are required. Reopen preserves exact responses; recovery grants no subsequent
editing or writable restart. Explicit Stop and ambiguous selected-candidate
recovery retain their documented holds.

Stop latches in memory before disk work. An owned drain appends and verifies
durable STOP after active work is accounted for. The immediate response
distinguishes PENDING, DURABLE and UNKNOWN persistence. Cleanup failure retains
the exact lifecycle owner.

Static discovery enables no capabilities. The concrete trusted host supplies
its enabled set. Artist-project paths, arbitrary scripts/native execution and
Play input remain outside this candidate. See `PUBLICATION_OWNER.md`,
`PUBLICATION_RECOVERY.md`, `CONTRACT.md` and the profile documents. Older
journal versions remain replay/regression dependencies with separate evidence.
