## Smallest deliverable
One fresh, host-owned managed project; one real Windows EditorPlugin process; one authenticated `scene.save` command from changed live scene through durable selected bundle and genuine live-editor reload/readback. Enable only `scene.inspect`/`scene.save` plus bounded lease/lookup/Stop control. Script replacement, arbitrary project paths, artist files, writable restart recovery and general editor automation remain disabled.
Keep one editor project root throughout. `res://` resolves there, not under the immutable flat `obj-*` store and not under a candidate's temporary directory. For `scene.save`, preserve all ten non-scene input files byte-for-byte; only the working mirror's `scenes/fixture.tscn` changes. This avoids changing the project's script/config/addon root during adoption.
Reload is an explicit history boundary in this first owned-fixture slice: require a checkpoint, declare that policy in the Godot save catalog/preview, reject old-generation undo/redo, and test actual EditorUndoRedo history after adoption. Do not silently claim history preservation or expose this restricted save as ordinary artist-project save until that contract is implemented and verified.

## Existing boundaries that must remain honest
`contract.validate_request` is pure; `ValidationContext` is not authentication. Current `plugin.gd` implements main-thread inspect/mutations, but no save/adoption transport. `semantic_editor_probe.gd` is a quitting diagnostic overlay, not the installed publication path.
`ValidationOwner.validate/bind_semantics/semantic_observation` yields an issuer-registered **isolated candidate** receipt, never a live editor session/adoption. Do not manufacture editor IDs or relabel a Linux validation run as the Windows editor.
`PublicationJournalV2._verify_bootstrap` currently requires the selector still equal bootstrap bytes/FileVersion; ordinary selector mutation would make refresh fail. `append(COMMITTED)` only records caller attestations. `ProtectedBundleStore.prepare_selection/select` already supplies actual generation CAS, native barriers and full readback, but no authorization.
`SessionAuthority` only permits fixture/control scopes. Its `fixture.write` is insufficient for Godot. `FileFixtureReleaseConsumer`, its registration marker and private rearm APIs must not be impersonated or reused to acquire Godot write authority. Reopened journals stay readonly.

## Ordered path and effect guards
1. Authenticate and resolve the **current registered** Godot grant; strict `Request.from_dict` plus `contract.validate_request` checks schema, exact operation/target/payload, payload hash, project, command ID/digest, deadline, current lease/fence, selected project revision/files and genuine editor generation/semantic snapshot. Bind negotiated catalog digest server-side because the existing Request has no catalog-digest field. Same ID/same digest returns the original registered status; changed digest rejects without poisoning healthy state.
2. Persist bounded `CAPTURE_PREPARED` with command/admission, selected checkpoint descriptor, real editor precondition and one host-generated scratch name before any `ResourceSaver` output. This records the scratch effect before the final candidate manifest or twelve native names exist; it must not pretend a provisional bundle is final PREPARED.
3. On the editor main thread, recheck session/root/generation/semantic precondition and a current single-use effect permit; `PackedScene.pack` the actual edited root, save to that fresh fixed scratch destination, then re-inspect unchanged live state. No `save_scene_as` that moves the live scene path. Capture owner reads actual saved bytes/hash, verifies all ten unchanged project inputs, and registers the capture; profile rejection leaves selection unchanged.
4. Validate those exact eleven bytes with `ValidationOwner.validate`; call `bind_semantics` to obtain the final immutable manifest and registered semantic receipt. Compare candidate semantic state to the captured Windows live state under S51's exact shared serializer; do not accept only matching property subsets. Validation may precede durable STAGED because it supplies final metadata; no extra engine pass solely to match log order.
5. Journal `prepare` reserves the final bundle's twelve names, then persists PREPARED before `stage_prepared` creates anything. Native stage/barrier/readback supplies STAGED; registered validator evidence supplies VALIDATED. Retain the selected previous complete descriptor as checkpoint. Scratch output is not public availability or durable selection.
6. Obtain an editor-ready barrier with the same root/session/generation, unchanged live save revision and all eleven working input hashes. Journal exact selector intent/old FileVersion and ACTIVATING before native CAS. Immediately before `store.select`, under the sole lifecycle/effect guard, recheck live registered grant, deadline, Stop/cancel flag, lease/fence and exact current selector. Persist a `SELECTED` fact with actual returned FileVersion/hash before dispatching adoption; refresh/reopen folds this expected-selector chain instead of comparing permanently with bootstrap.
7. Adoption is another separately guarded effect. The editor owner reads the selected twelve protected objects, decodes the manifest, verifies all ten unchanged mirror files, atomically replaces only the fixed scene mirror after expected-old-byte/identity checks, and requests `reload_scene_from_path("res://scenes/fixture.tscn")` through the genuine plugin. This disposable mirror is not the authoritative selected store; it must be privately owned, path/reparse checked and single-writer. No generic native-root rearm is needed.
8. Drain the reload completion through bounded frames; require a new bound root/reload generation in the same registered editor session and exact expected scene path. Fresh resource loading/import-cache handling must be exercised, not inferred from calling reload. Read back actual mirror source hashes, script/UID resolution, full semantic bytes and selection identity after adoption. Compare with both protected selected bytes and the final registered candidate receipt; then record READBACK and durable COMMITTED with custody high-water/native readback.
9. Only the authenticated owner may produce a public committed response after all preceding effects/receipts match and source/session/selection still match. The pure reducer and storage receipts keep `public_ack=false`. During development, discovery/public ACK stays disabled until this complete path and its race cuts pass; diagnostic success alone is insufficient.

The cross-process effect permit needs a real linearization rule, not an admission-time token: editor-ready → host rechecks under authority/lease gate → one bounded in-flight phase → main-thread consume/recheck with no intervening await → completion/unknown. Stop sets its fence flag before waiting for storage locks; revocation/lease replacement cannot acknowledge completion while an older permitted phase remains unaccounted. After linearization an already-started bounded effect may finish, but no next effect starts. Lost/late permit, expired deadline, callback queued across reload, broken channel or uncertain drain becomes UNKNOWN. Test the grant-to-main-thread window explicitly; a stale queued permit is not an effect guard.
Never hold accepted core `Journal.lease_guard` over disk I/O/IPC; its contract forbids that. The new Godot owner supplies its own bounded phase admission/lease lifecycle and checked effect boundary. Long Linux validation/import waits release lifecycle scheduling locks; they cannot block authenticated Stop processing.

## Crash/race cuts and bounded verification
- Before capture/stage effect: ordinary rejection/cancel, no selection change. Partial scratch/stage: retain ownership/evidence and original names; no automatic retry or deletion pretending a clean no-effect result.
- After ACTIVATING but before/after CAS, or after mirror replacement but before live adoption: UNKNOWN/held. Current selected bytes may be candidate while editor remains old; never report COMMITTED or automatically restore/replay. Preserve both versions and actual selector facts.
- After actual readback but before durable terminal/custody: UNKNOWN until explicit reconciliation; never synthesize an ACK from the engine message. After durable terminal, same digest lookup returns original receipt without repeating capture/CAS/reload.
- Restart opens journal/store readonly, checks actual selector against the complete durable chain, and reports pending/held. A future verified restart authority is separate work; no `_fixture_file_consumer`/inert-marker trick or private rearm.
- Focused tests: fixture credential denial, grant rotation/revoke, wrong catalog/project, stale lease/fence/deadline/Stop at each effect, genuine PID/session/root reload drift, manual edit during validation, changed non-scene byte/UID/reference, stale cache, same-ID conflict/retry, selector same-byte/new-FileID, and every durable cut above.
- Actual bounded integration: start the real pinned EditorPlugin on the complete owned project, make a visible scene transform through existing semantic commands, authenticated save, actual selector generation CAS, same-editor adoption and full readback, then clean owned-process teardown and readonly journal reopen. Capture raw host/IPC phase facts without secrets, native descriptors, original/final hashes and complete frozen source. One full closure remint at this integration boundary; focused tests during edits.
