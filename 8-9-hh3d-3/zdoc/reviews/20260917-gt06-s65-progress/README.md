## Lessons retained

Pin identity before retirement/close; closed owners correctly reject identity
access. A successful native exit does not prove camera/phase freshness. Flush
input edges together before readback. Preserve exact native JSON bytes for
float-bearing hashes. Standard screenshot sRGB metadata requires a bounded
GT06 decoder adapter; it does not justify widening the accepted GT05 texture
profile. New postprocessing validators bind their own sources separately from
the native run they inspect.
