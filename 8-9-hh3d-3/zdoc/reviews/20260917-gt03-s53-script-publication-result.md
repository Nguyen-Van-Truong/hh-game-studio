Attempt `script-publication-01` is retained as failed diagnostic evidence.
Its authenticated preview/no-effect/typed rejection checks passed; the probe
incorrectly tried to acquire a second active write lease. The probe now takes a
read lease for preview and its first write lease only for mutation. Static
review also corrected comparing full manifest rows (which include `role`) to
native working-file rows (SHA256 and byte count). No runtime source was changed
to accommodate these probe corrections.

Current scope is the owned trusted fixture and closed declarative script
profile, using real Windows EditorPlugin processes in headless editor mode and
actual isolated Linux validation. This does not establish arbitrary script
support, live artist UI input serialization, crash fault injection at every
journal phase, or complete GT-03 acceptance.

The internal `open_selected_generation` API currently does not consume its
registered retirement receipt, so trusted in-process code could request more
than one successor using the same receipt. The present public coordinator
serializes the transition and deduplicates requests; it does not expose that
internal reuse path. A single-use successor reservation must be addressed
before opening writable recovery or general lifecycle reuse. No runtime guard
was added during this frozen S53 verification.
