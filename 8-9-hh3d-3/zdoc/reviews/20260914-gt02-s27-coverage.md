adapter inside GT-02. Section 2.2 and original P-15 explicitly permit fixed
`UNSUPPORTED_SAFE_OPEN_WINDOWS` with consumer file mutation disabled when a
secure primitive cannot be supplied. TX15 still calls unavailable safe-open a

valid reason to keep the write capability disabled.

from independent Python/Node/Godot consumers. The Godot tagged-value harness
can satisfy that serialization requirement: it receives values, scalar
codepoints and numeric bits, not expected canonical output. Its result must
not be relabeled raw JSON parser conformance. The current Python host is the
raw-wire admission boundary and must reject invalid wire before dispatch now.
A future Godot adapter must use that validated boundary or prove its own raw
parser before exposing one. Native Godot JSON parsing is not automatically safe
for U+0000, duplicate keys or numeric admission because serializer vectors pass.
