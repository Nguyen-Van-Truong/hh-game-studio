# Capability matrix — Godot 4.7.1-stable 2D workflows (R1-WP1)

Pin: **4.7.1-stable** official `a13da4feb` (`4.7.1.stable.official.a13da4feb`).
Standard (not Mono/.NET). Game scripts: typed GDScript.

This file replaces the slogan “the agent can press all buttons.” One row is one
**concrete workflow** (example: add a Node2D child named X under the selected
parent), not a category slogan (“nodes”).

`addons/hh_agent` **EXISTS** under `godot/plugin-project/addons/hh_agent`.
Vendor MCP addons must **not** be cloned into `godot/plugin-project/`. Named
`EditorInterface` methods are agent-usable **only** through a named plugin
action that an official E2E test ACKs.

## Status honesty

| Status | Meaning |
|--------|---------|
| **Supported** | A **named `action_id`** plus an official E2E test path that ACKs it, **or** a stock **Godot CLI** invocation already proven (pin 4.7.1-stable). `EditorInterface` may appear on Supported rows because the plugin exists. Not every P0 is Supported. |
| **Alternative** | Same outcome via text `.tscn` / `.gd` / `project.godot` / `.import` plus optional `godot --headless --import`, or a typed substitute (PlaceholderTexture2D, AudioStreamGenerator, editor save/reopen instead of F5). Owner/backlog is required when this is the P0/P1 2D proof. |
| **Gap** | Missing semantic command, runtime bridge (R6), or export/templates (R9). Play/debug/export P0 rows stay Gap/Alternative until R6/R9. `play.start` stays `E_UNVERIFIED`. |

Priority: **P0** = required to dogfood R8 Kho Bí Ẩn; **P1** = polish / nicer API;
**P2** = third-party plugin, not on the stock path (do not enable addons here).

Godot 4.7.1 names: **TileMapLayer** (not legacy TileMap as the 2D default);
**AnimationPlayer** extends **AnimationMixer**; 2D frame anims often
**AnimatedSprite2D** + **SpriteFrames**.

Undo: scene objects use `EditorUndoRedoManager` through `addons/hh_agent` (A3).
Text-file Alternatives undo with file revert / Git. Durable save is still
`EditorInterface.save_scene` / `ProjectSettings.save` / `ResourceSaver` + disk
readback — not UndoRedo alone. Trace ledger: [COVERAGE_2D.md](COVERAGE_2D.md).
